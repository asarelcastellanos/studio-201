Updated 2026-11-19. Times are Pacific. Numbers are examples. Covers spec claims C4 to C12.

Width. About 20 columns, down from 35. Every value gets its own line, because you have height to spare and width is what the chat needs.

Header. Product, main model, and "Board ↗", which opens that product's GitHub board in the browser.

Context. Bar, percent, used of total.

Usage. Reset times are actual Pacific times, not countdowns, so you can plan around them. Each window gets its own forecast line.

Agents. Running only. Finished agents collapse into one line.

7. Narrow terminal

Below about 144 columns, Claude Code won't dock a pane on its own. /studio opens it at any width, and × closes it. At your usual 263 columns it opens with the session.

Assumptions

Updated for the side pane. A4 and A8 changed. The rest still need your answer.

A1 · Forecast methodStraight-line projection from recent pace: last 30 minutes for 5h, last 24 hours for 7d.
ForReacts quickly when you speed up.
AgainstA burst of heavy work can give a false warning. Average pace since the window opened is calmer but slower.
A2 · ReadingsThe percent is account-wide, but readings are only taken while a session runs here.
ForNo background process.
AgainstUsage elsewhere shows in the percent, not in the pace, until the next reading.
A3 · Dollar costI show the engine's cost estimate.
ForComparable across sessions. Your current monitor shows it too.
AgainstOn a subscription it isn't what you pay.
A4 · One pane (changed)All mods live in one docked pane. Nothing above or below the prompt.
ForWhat you asked for. The prompt area stays clean.
AgainstTakes about 20 columns from the chat. Every value on its own line, so with many agents the pane scrolls.
A5 · Pacific timeAll times in Pacific, with real times instead of countdowns.
ForWhat you asked for. Easier to plan around.
AgainstYour current monitor shows "resets 1h 57m". Countdowns are quicker to read for the 5h window. We could show both for 5h.
A6 · Run timeThe mod records when agents finish, since the engine gives the start time only.
ForGives "ran 6m".
AgainstAgents that finished before the mod loaded show no run time.
A7 · Command name/studio opens the pane. (/agents is built in.)
ForOne command for the whole pane.
AgainstNone found.
A8 · Opens with the session (changed)On wide terminals, the pane opens when the session starts and stays open.
ForSame as your monitor today.
AgainstAlways uses the space, even when nothing runs.
A9 · Board link sourceEach repo stores its board URL in .studio/config.json.
ForNo lookup each time.
AgainstOne more file per repo.
A10 · OrderLongest running first.
ForA stuck agent rises to the top.
AgainstThe newest work sits lower.
A11 · Replaces Claude MonitorStudio 201 rebuilds this pane from scratch instead of reusing the workbench's monitor code. I keep its layout because it works for you.
ForKeeps the new repo clean, as you asked.
AgainstRewrites working code. Both monitors shouldn't run at once, so the old one gets turned off when Studio 201 installs.
