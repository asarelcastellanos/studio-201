## What v0.1 is

One Claude Code plugin named `studio-201`, at the root of the repo. The repo is also its own plugin marketplace, so one command installs it. The plugin has three parts:

| Part | What it is | Claims |
|------|------------|--------|
| Agents | One markdown file per team role, with its model and tool list | C13 |
| The mod | TypeScript inside Claude Code: side pane, policy, `/studio` and `/board` | C1, C4-C12, C14, C15, C17 |
| Rules | `AGENTS.md`: writing, git flow, decisions log, model roles. Read by Claude and Codex | C2, C3, C16 |

## How the hard parts work

- **Install:** `/plugin install studio-201 --marketplace asarelcastellanos/studio-201`. The first session after install runs setup once and asks before changing anything.
- **Connecting ~/.claude:** setup copies `AGENTS.md` to `~/.claude/studio-201/AGENTS.md` and adds one import line to `~/.claude/CLAUDE.md`. Codex gets a link at `~/.codex/AGENTS.md`.
- **Update:** `/studio update` runs `claude plugin marketplace update` and `claude plugin update`, refreshes the `AGENTS.md` copy, reloads, and prints the old and new versions.
- **Usage:** Claude Code gives mods the context fill, cost, and 5h and 7d percent with reset times. The mod takes a reading each turn.
- **Forecast:** readings are kept on each Mac, about 7 days' worth. A straight line through recent readings gives the time 100% is reached, compared with the reset time.
- **Agents:** Claude Code lists agents with model, start time and tokens. The mod records finish times. A click asks Claude Code to show that agent's transcript.
- **Policy:** the mod sees every tool call first. It refuses file edits from the main session, and any `gh pr merge` or `git push` that targets main.

## Risks

| Risk | If it happens |
|------|---------------|
| Update can't reload by itself | `/studio update` ends with "Run /reload-plugins". |
| Mod code can't be split into files | Everything goes in `register.tsx`, by section. |
| The mod API changes | `plugin.json` records the Claude Code version it was built against. |
| No limit reading before the first reply | The pane shows "no reading yet" (C7). |
| Workbench and Studio 201 both active | Setup turns the workbench mods off. If I decline, the pane warns once. |
