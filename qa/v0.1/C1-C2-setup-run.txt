C1 and C2 global part: src/setup.ts run against a scratch HOME

Method: node 26 runs the repo src/setup.ts (copied to the scratch dir with the two relative imports given a .ts suffix; no other edit).
It calls runSetup($) with a mock $. fs, env, store, ui and command are mocked. readlink and ln run for real against the scratch HOME.
The `claude` CLI is never started: `claude plugin list --json` returns [], so the workbench-disable step is not exercised.
HOME and CLAUDE_CONFIG_DIR both point under the scratch dir, and the harness refuses to run if HOME is elsewhere. The real ~/.claude, ~/.codex and settings.json were not touched.
Source: origin/feature/foundation at c3b5cbc (PR #39 merged).
